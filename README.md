# الترندات — محرّك الرصد

موقع عربي متعدد البلاد ينشر "الأكثر بحثًا اليوم"، بنسخة لكل بلد.

**الموقع الحي: [altrendat.com](https://altrendat.com)**

## التشغيل

```
python engine/pipeline.py eg     # التقاط + إثراء + تصنيف لبلد واحد
python engine/writer.py          # كتابة الشروح (يتطلب ANTHROPIC_API_KEY)
python engine/cards.py           # توليد كروت 1200x675
python engine/entities.py        # تحديث ذاكرة الكيانات
python engine/render.py          # توليد output/index.html
```

بلا وسيط، يعالج `pipeline.py` كل بلد عليه `"enabled": true`.

## البنية

| الملف | الدور |
|---|---|
| `engine/countries.json` | بلد واحد = كتلة إعدادات. إضافة بلد لا تتطلب كودًا |
| `engine/pipeline.py` | الالتقاط، استخراج `og:`، التصنيف، حكم الأمان |
| `engine/writer.py` | كتابة الشرح العربي بنموذج Claude |
| `engine/arabic.py` | تشكيل النص العربي للرسم — بلا مكتبات خارجية |
| `engine/cards.py` | كارت 1200×675 لكل ترند (شرط Discover) |
| `engine/entities.py` | ذاكرة الكيانات — تتراكم عبر الأيام والبلاد |
| `engine/render.py` | لوحة معاينة HTML (RTL) |
| `data/trends.json` | مخرجات اليوم |
| `data/entities.json` | الذاكرة التراكمية |

## لماذا طبقة الإثراء

Google Trends RSS يعطي العنوان وحجم البحث و3 أخبار (عنوان + رابط فقط).
حقلا `description` و `news_item_snippet` **فارغان دائمًا**، وكل منافس
يحصل على نفس الملف. لذلك يجلب المحرّك صفحات الأخبار نفسها ويستخرج
`og:description` — النص الذي لا توفره Google — وعليه تُبنى الصفحة.

## طبقة الأمان

لا يُنشر ترند تلقائيًا إذا:
- ورد فيه لفظ من `BLOCKED_KEYWORDS` (وفيات، جرائم، قضايا، أمراض)
- بدا عنوانه اسم شخص ولم يطابق أي فئة
- لم يُستخرج نص من خبرين على الأقل (صفحة رقيقة)

هذه الحالات تنتظر نقرة بشرية. القاعدة موجودة لأن النشر التلقائي عن
شخص حقيقي مذكور بالاسم خطر قانوني، ولأن الصفحات الرقيقة هي سبب
رفض AdSense الأول.

## التشغيل الآلي

`.github/workflows/trends.yml` يشغّل السلسلة كل 20 دقيقة.

اجعل المستودع **عامًا** — الجدولة كل 20 دقيقة تستهلك ~2160 دقيقة شهريًا،
وهو أكثر من 2000 دقيقة المجانية في المستودعات الخاصة. المفاتيح كلها في
GitHub Secrets ولا شيء منها في الكود.
