OpenAI releases GPT-6.1 Sol for GitHub Copilot with improved coding efficiency

By Karim Fouad · Published 29 Sep 2026, 18:15 UTC

GPT-6.1 Sol, OpenAI's latest model, is now generally available in GitHub Copilot and uses noticeably fewer tokens and steps than earlier GPT-6 and GPT-5.6 models while completing multistep coding tasks.

Quick facts

Availability
GitHub Copilot Pro+, Max, Business, and Enterprise users
Billing model
Usage-based billing at provider list pricing
Performance improvement
Uses noticeably fewer tokens and steps than GPT-6 and GPT-5.6 families

GPT-6.1 Sol completes coding tasks while consuming fewer tokens and requiring fewer steps than previous generations. In early testing, the model demonstrated reliable task completion with noticeably reduced token consumption and fewer steps needed compared to earlier models in the GPT-6 and GPT-5.6 families.

The model matters for software developers because it enables more efficient agentic coding and terminal workflows. Fewer tokens mean lower costs per interaction, while reduced steps accelerate task completion. The efficiency gains allow developers to work on complex programming challenges with better resource management.

GPT-6.1 Sol is available to Copilot Pro+, Max, Business, and Enterprise users and can be selected through the model picker in their interface. The rollout is happening gradually, so users may need to check back before accessing it. GitHub Copilot Business and Enterprise administrators can manage access to GPT-6.1 Sol through the model policy in Copilot settings. Under default model enablement, new models are automatically enabled unless an administrator has turned off the global default or explicitly disables this model. The service uses usage-based billing at provider list pricing.
